# 游戏完整系统研究

研究可供开发参考的完整业务系统：说明管理对象、状态、玩家操作、资源或进度如何流转。交互机制可以作为系统内专题。开题写明对象、用途、版本、证据范围和验收范围，沿真实前态、动作、反馈与后态查证；源码、发行物、录像、实际操作与推断分别记录。

在包外案例目录保存 Markdown 主本、必要证据、原型、素材许可和测试。报告保留条件、例外、未知与完整过程；无原作依据的补全注明假设或用户决定，不把机制演示验收为高保真还原。重要规则缺证只暂停依赖路径，其他有依据的工作可继续。

需要同源 HTML 和持续试玩时，使用[阅读页与原型浮层合同](reader-contract.md)。完整目录、按需领域导读与原型入口来自同一份 reader.json。首次打开加载原型，关闭保留 iframe，再开继续；实际测试焦点、阅读位置、Esc 优先级及输入隔离。

编辑沿[编辑与回执合同](../deep-game-analysis/report-polish.md)，工具执行、人工审订、内容审计和真实浏览器结果分别记录。未配置外部工具仍可完成基础研究与表达。

本包不附维护者的研究案例、游戏素材、报告、运行和账号。使用者在包外维护自己的案例索引；研究不自动写入 Knowledge 或修改产品。
