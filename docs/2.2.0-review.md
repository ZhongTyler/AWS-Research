All existing license, notice, provenance, lock and archived vendor payload bytes are retained. This release adds first-party reusable source and public adaptations; it does not refresh third-party sources. source-review records identify frozen source, not a claim that this public package is byte-identical to that repository.

This diagram describes document routing and capability boundaries. It does not measure automatic Skill selection or guarantee the agent will always choose the appropriate tool. Actual delivery records which methods, sources and tools were used, their inputs, outcomes and remaining gaps.

Validation uses synthetic local inputs: 48 Python tests (11 system reader, 8 navigation build, 29 expression), deterministic navigation-mode tests, actual headless Edge on HTTP/file at desktop/phone widths, configured-executor offline preparation and identity failures, static dependency audit, source projections, new-link/privacy checks, module inventory and isolated upgrade/conflict/rollback. The browser checks verify state, focus, scroll, Escape and layout; no human comprehension or real-game acceptance is inferred. Static dependency audit flags dynamic iframe src assignment for manual resolution, covered by the browser test and declared local prototype dependency. It does not claim the single HTML embeds the prototype.

No model, paid or online request was made. The optional executor test uses an explicitly configured local API with synthetic input; it does not establish a bundled or public online service. Missing configuration, source drift and wrong-version receipts fail explicitly. Whole-report editing, semantic adoption and arbitrary custom renderer writeback retain their own checks.

Website impact: the system report's persistent prototype overlay and actual execution/whole-report versus per-item review evidence are additions. System research, same-source text/visuals, sequential and domain reading were already represented. A website update and public release remain the release owner’s separate actions.
