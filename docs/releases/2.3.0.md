# Research 2.3.0

新增可独立使用的研究清单规则：保留目标与选择依据，同题续接，研究、本地接受及线上同步分别回核。提供包外空白模板，不携带维护者的真实队列或报告。

Adds standalone backlog maintenance preserving goals and selection context, one current record per question and separate research/local/online receipt status. Includes a recipient-owned blank template, no private queue or reports.

## Scope and source

Reviewed generic adaptation from native `03a27402d918a541e9383bb45e56380afd24b04f` onto public 2.2.0. Private project state, real research queue/cards/reports, native fixed paths and production service receipts are excluded. Existing execution code and optional dependencies stay unchanged. AWS, meta, Knowledge and separate Tools/Skills are optional. The Research execution hook is updated by the designated Skill maintainer and points to this package's single backlog contract.

## Upgrade and recovery

Preserve old checkouts and recipient-owned data; verify this module with `python .module/module_manager.py verify`, compare changes and switch callers explicitly. AWS installations use the aggregate upgrade preview, edit-conflict refusal and transaction rollback. Use the blank backlog template in a new recipient-owned location only when needed; never replace an existing queue wholesale. Unavailable optional methods use the package standards and retain the actual evidence limits. Installation does not run research, start services, enable scheduled work or deploy a website.
